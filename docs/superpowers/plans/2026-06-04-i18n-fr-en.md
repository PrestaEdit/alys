# Support multilingue FR / EN — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ajouter l'anglais à côté du français, avec auto-détection de la langue du téléphone (en-tête `Accept-Language`) au premier lancement et choix manuel persistant dans les Réglages.

**Architecture:** Un middleware `SetLocale` (prepend au groupe `web`) résout la locale dans l'ordre `Setting('locale')` → `Accept-Language` → fallback `fr`, et applique `app()->setLocale()` + `Carbon::setLocale()`. Toutes les chaînes FR en dur sont extraites vers `lang/{fr,en}/<domaine>.php` et appelées via `__('domaine.cle')`. Les dates Carbon en `.locale('fr')` deviennent dépendantes de la locale active.

**Tech Stack:** Laravel 11 (bootstrap/app.php middleware), Livewire 3 / Blade, NativePHP mobile (WebView), Pest pour les tests, store clé/valeur `Setting`.

**Spec de référence :** `docs/superpowers/specs/2026-06-04-i18n-fr-en-design.md`

---

## Conventions d'extraction (valables pour toutes les tâches d'extraction)

Pour chaque vue/composant d'un domaine :

1. Repérer chaque chaîne destinée à l'utilisateur (texte visible, `placeholder`, `label`, `title`, messages de toast/dispatch, titres passés à `->layout(..., ['title' => '...'])`).
2. Ajouter une clé dans **`lang/fr/<domaine>.php`** (valeur = texte FR exact actuel) **et** dans **`lang/en/<domaine>.php`** (traduction EN).
3. Remplacer la chaîne dans le code :
   - Blade : `Accueil` → `{{ __('nav.home') }}` ; attribut `label="Accueil"` → `label="{{ __('nav.home') }}"`.
   - PHP (Livewire) : `'Accueil'` → `__('nav.home')` ; `message: 'Texte'` → `message: __('domaine.cle')`.
4. Nommage des clés : `snake_case` descriptif (`empty_state`, `save`, `next_visit`). Boutons réutilisés → `common.*`.
5. **Ne pas traduire** les données saisies par l'utilisateur (noms de profils/traitements), les classes CSS, les routes, les icônes.

**Vérification d'un fichier extrait :** plus aucun littéral français visible dans le fichier. Commande type (adapter le chemin) :
```bash
grep -nE "[A-Za-zÀ-ÿ]{3,}" resources/views/livewire/<fichier>.blade.php | grep -vE "__\(|route\(|wire:|class=|x-|svg|path|viewBox|stroke|fill" 
```
Inspecter manuellement le reste : il ne doit rester que du markup, des clés `__()`, des noms de variables.

- [ ] **Step 3 : Créer le middleware**

Créer `app/Http/Middleware/SetLocale.php` :
```php
<?php

namespace App\Http\Middleware;

use App\Models\Setting;
use Carbon\Carbon;
use Closure;
use Illuminate\Http\Request;
use Symfony\Component\HttpFoundation\Response;

class SetLocale
{
    /** Langues supportées par l'application. */
    private const SUPPORTED = ['fr', 'en'];

    public function handle(Request $request, Closure $next): Response
    {
        $locale = $this->resolve($request);

        app()->setLocale($locale);
        Carbon::setLocale($locale);

        return $next($request);
    }

    private function resolve(Request $request): string
    {
        // 1. Choix manuel persisté
        $stored = Setting::get('locale', '');
        if (in_array($stored, self::SUPPORTED, true)) {
            return $stored;
        }

        // 2. Auto-détection depuis l'en-tête de la WebView
        $preferred = $request->getPreferredLanguage(self::SUPPORTED);
        if (in_array($preferred, self::SUPPORTED, true)) {
            return $preferred;
        }

        // 3. Fallback
        return 'fr';
    }
}
```

Note : `Request::getPreferredLanguage(['fr','en'])` renvoie le premier supporté correspondant à `Accept-Language`, et le **premier de la liste** (`fr`) si aucun ne correspond — ce qui assure le fallback français.

- [ ] **Step 4 : Enregistrer le middleware (prepend au groupe web)**

Créer `tests/Feature/TranslationParityTest.php` :
```php
<?php

namespace Tests\Feature;

use Tests\TestCase;

class TranslationParityTest extends TestCase
{
    public function test_fr_and_en_have_identical_keys(): void
    {
        $frDir = base_path('lang/fr');
        $enDir = base_path('lang/en');

        $files = collect(glob($frDir.'/*.php'))->map(fn ($p) => basename($p));

        foreach ($files as $file) {
            $this->assertFileExists($enDir.'/'.$file, "Manque lang/en/$file");

            $fr = $this->flatten(require $frDir.'/'.$file);
            $en = $this->flatten(require $enDir.'/'.$file);

            $this->assertSame(
                array_keys($fr),
                array_keys($en),
                "Clés divergentes dans $file"
            );
        }

        // Réciproque : pas de fichier EN orphelin
        foreach (glob($enDir.'/*.php') as $p) {
            $this->assertFileExists($frDir.'/'.basename($p), 'Fichier EN orphelin : '.basename($p));
        }
    }

    private function flatten(array $arr, string $prefix = ''): array
    {
        $out = [];
        foreach ($arr as $k => $v) {
            $key = $prefix === '' ? (string) $k : "$prefix.$k";
            if (is_array($v)) {
                $out += $this->flatten($v, $key);
            } else {
                $out[$key] = $v;
            }
        }
        return $out;
    }
}
```
